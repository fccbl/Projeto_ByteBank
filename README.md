# ByteBank

Projeto da disciplina BD015 - Algoritmo e Estrutura de Dados, sistema bancário simples feito em Python.

## Integrantes

- Ana Clara Fornellos

## O que o sistema faz

Por enquanto o ByteBank tem as operações básicas de uma conta:

- Consultar saldo
- Depositar
- Sacar

O programa roda em um menu que fica repetindo até o usuário escolher sair. Ele não deixa fazer depósito ou saque com valor negativo ou zero, e também não deixa sacar mais do que o saldo disponível.

Mais pra frente o projeto vai ganhar múltiplas contas, transferência PIX, extrato com estorno e fila de pagamentos agendados.

## Como executar

É só ter o Python instalado e rodar:

```
python main.py
```

No menu, digite o número da opção desejada.
